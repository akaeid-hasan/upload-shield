# Contributing to UploadShield

Thanks for your interest in improving UploadShield.

## Bug Reports

When opening a bug report, please include:

- WordPress version
- PHP version
- UploadShield version
- User role used during the upload
- Configured image-size limit
- Image type and file size
- Steps to reproduce the issue
- The exact error message, if available

Please avoid posting passwords, API keys, private server information or other sensitive data.

## Pull Requests

Keep changes focused and compatible with WordPress coding practices. Explain what the change does, why it is needed and how it was tested.

## Feature Requests

Feature suggestions are welcome when they stay aligned with UploadShield's goal: simple, lightweight control over image upload size in WordPress.
