# Changelog

## 1.0.1 — 2026-10-04

- Removed all reminder frequency and disable controls from the settings screen.
- Dashboard support reminder now uses a fixed 15-day cycle.
- Closing the reminder hides it for 15 days for that administrator, then it can appear again.
- Removed reminder status text from the UploadShield settings UI.

## 1.0.0 — 2026-10-04

- Initial UploadShield release.
- Added administrator image upload limit.
- Added separate image upload limit for other users.
- Added KB and MB unit controls.
- Added clear oversized-image upload errors.
- Added responsive branded settings interface.
- Added dashboard-only support reminder.
- Added per-administrator dismissal scheduling.
- Added clean uninstall routine.
